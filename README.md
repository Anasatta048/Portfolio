# Anas Atta — Portfolio

GitHub-themed, single-page portfolio. Pure **HTML + CSS + vanilla JS**, with **GSAP 3** (ScrollTrigger, ScrollToPlugin, Flip) and **Three.js r128** from cdnjs. You don't need a build step or npm to run it.

```
index.html            markup, SEO/OG/JSON-LD, SVG icon sprite
css/style.css         variables → base → layout → components → animations → utilities → responsive
js/data.js            ALL content: profile, projects, filters, language colours
js/screens.js         slug → local screenshot map (generated by tools/capture.js)
js/three-hero.js      Three.js "git-graph constellation" hero background
js/main.js            rendering, animation system, modal, palette, form, cursor, easter egg
assets/screens/       full-page project screenshots (<slug>.webp / .png)
assets/img/           avatar, favicon, OG image
tools/capture.js      one-time Playwright script → screenshots + js/screens.js
tools/projects.json   slug + URL list used by capture.js
```

Run it locally by opening `index.html`, or start a server with `python3 -m http.server`.

## Add a new project

1. Open `js/data.js` and copy an object in `PROJECTS`:

   ```js
   {
     slug: "my-app",              // unique; also the screenshot filename
     name: "My App",
     repoName: "my-app",
     url: "https://my-app.com/",  // null if not deployed
     repo: null,                  // public GitHub URL, or null = "Source is private"
     host: "Vercel",              // shows "Deployed on Vercel" (null = "Deployed · production")
     featured: true,              // appears in the pinned horizontal "Projects" showcase
     pinned: false,               // appears in Overview → Pinned
     cats: ["Full Stack", "API"], // filter tabs: Full Stack, Frontend, Backend, API, Automation
     lang: "PHP", icon: "zap",    // icon = any #i-<name> symbol in index.html
     year: "2026", updated: "Nov 2026", stars: 10, forks: 2,
     tags: ["Laravel", "React"],
     desc: "One-line summary.",
     impact: "Longer description shown in the card and modal.",
   }
   ```

2. If it has a live URL, add `{ "slug": "my-app", "url": "https://my-app.com/" }` to `tools/projects.json` and capture a screenshot (next section).

The repository counters, filter counts, showcase counter (`01 / 06`), command palette and search all update from the data automatically.

## Capture or swap screenshots

```bash
cd tools
npm install
npx playwright install chromium
node capture.js
```

```bash
node capture.js talk-to-trader gmb-manager
```

The first command captures every project; the second captures only the slugs you name. The script opens each URL at **1440px** width and scrolls the page so lazy content loads. It saves a full-page shot to `assets/screens/<slug>.webp`, or `.png` if `sharp` isn't installed, and regenerates `js/screens.js`.

To use your own image instead, drop it in `assets/screens/` and add `"slug": "assets/screens/slug.webp"` to `js/screens.js`.

**Fallback order:** a local screenshot in `js/screens.js` → the live screenshot service (`CONFIG.screenshotService` in `main.js`, which uses thum.io by default) → a styled placeholder.

## Change colours / theme

- Every colour is a CSS variable at the top of `css/style.css`: `:root` (dark, the default) and `:root[data-theme="light"]`. These are GitHub's palettes (`--bg`, `--surface`, `--accent`, `--green`, …, plus the contribution scale `--lv0…--lv4`).
- The hero's 3D colours are in `CONFIG.palette` in `js/three-hero.js`.
- Your theme choice is saved in `localStorage` (`theme`). The site follows `prefers-color-scheme` until a visitor picks a theme.

## Contact form

The form is in `index.html` (`#contact-form`). If `data-endpoint` is empty, submitting opens the visitor's mail client with the message pre-filled. To deliver messages with no mail client involved, set `data-endpoint="https://formspree.io/f/xxxx"`.

## After deploying

Replace `https://anasatta048.github.io/portfolio/` with your real URL in the `canonical`, `og:*`, `twitter:image` and JSON-LD tags in `index.html`.

## Animations — where to tweak

Most speeds and distances live in `CONFIG` at the top of `js/main.js`.

| # | Animation | Where | Tweak |
|---|-----------|-------|-------|
| 1 | **Right-to-left entrance** (signature) on headings, cards, README, skill cards, timeline, buttons | `initDataAnims()`; declared in HTML with `data-anim` | `CONFIG.rtl` (`x: 120`, `duration`, `ease`, `start`, `stagger`) and `CONFIG.rtlMobile`. Per element: `data-anim="rtl\|ltr\|up\|fade\|scale"`, `data-delay`, `data-stagger` (staggers the children), `data-x`, `data-duration` |
| 2 | **Pinned horizontal projects**: scrub 1, snaps to each card, progress bar + `01 / 06` | `initPinnedShowcase()` | `scrub`, `snap.duration`; turns on at `CONFIG.pinBreakpoint`. Reverse direction with `x: () => dist()` and a negative start offset |
| 3 | Skill bars fill 0 → value with counting numbers; language bar wipe | `initSkillBars()`, `initCounters()` | `duration: 1.4`; values come from `data-value` / `data-count` in HTML |
| 4 | Hero headline split into chars, sliding in from the right; role typing with blinking caret | `heroIntro()`, `splitChars()`, `typeLoop()` | `CONFIG.heroChars`, `CONFIG.typing`; typed strings are `profile.typed` in `data.js` |
| 5 | Scroll progress bar (green) | `onScroll()` | colour: `.scroll-progress span` |
| 6 | Header blur + shrink after scrolling | `onScroll()` → `.is-scrolled` | `.site-header.is-scrolled` in CSS |
| 7 | Smooth anchors + sliding tab underline | `scrollToId()`, `moveIndicator()` | duration in `scrollToId`; underline colour `.tabs__indicator` |
| 8 | Parallax (hero grid, terminal card) | `initParallax()`; `data-speed` in HTML | `data-speed="0.25"` (+ slower / − faster) |
| 9 | Preloader (terminal "git clone…") → curtain reveal | `runPreloader()` | `CONFIG.preloaderMs` |
| 10 | Lighter on mobile; reverted and rebuilt on resize | `initAnimations()` uses `gsap.matchMedia()` | breakpoints in the `mm.add({...})` conditions |
| 11 | Screenshot "live page" scroll on hover / in view on touch; wheel scroll; fake cursor; address-bar loading bar; skeleton → image | `bindLiveScroll()`, `loadBrowser()` | `CONFIG.screenScrollSpeed` (px/s), `CONFIG.screenReturn` |
| 12 | 3D tilt + glare on cards | `bindTilt()` | `CONFIG.tiltMax` |
| 13 | Magnetic buttons (`data-magnetic`) | `bindMagnetic()` | `CONFIG.magnetStrength` |
| 14 | Contribution graph wave (newest → oldest, right-to-left) | `buildContrib()` | `stagger` function in `buildContrib` |
| 15 | Repo filter shuffle (GSAP Flip) | `initFilters()` | `Flip.from({ duration, stagger })` |
| 16 | Drawer slides in from the right; command palette; toasts | `openProject()`, `openPalette()`, `toast()` | durations inline |
| 17 | Three.js constellation: drift, mouse parallax, spreads on scroll | `js/three-hero.js` | `CONFIG.driftSpeed`, `parallax`, `spreadOnScroll`, `dollyOnScroll`, `nodes` |
| 18 | Theme switch circular reveal (View Transitions API) | `toggleTheme()` | `duration: 550` |
| 19 | Easter egg: Konami code or type `git push` → confetti | `initEasterEgg()`, `celebrate()` | particle count / colours in `celebrate()` |

`prefers-reduced-motion` turns off GSAP motion, the preloader, the Three.js scene (the CSS gradient shows instead), the custom cursor, tilt, typing and confetti. Every element still renders in its final state.

**Shortcuts:**

- <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd> opens the command palette.
- <kbd>/</kbd> focuses the search box.
- <kbd>Esc</kbd> closes overlays.
- <kbd>Ctrl</kbd> + <kbd>Enter</kbd> sends the contact form.
