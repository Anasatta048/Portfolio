    # Hi, I'm Anas 👋

    Full Stack Developer building production web apps with Laravel and React.js — based in Gujranwala, Pakistan.

    Close to two years shipping real products across three teams — booking and quote engines, an ERP/POS suite, HR systems, a UK + US business directory, Google-API integrations, WordPress customisations and Python / Chrome-extension scrapers. I own features end to end: designing the database schema, writing the REST APIs and background jobs, then building the interface on top — and deploying it on Linux (Docker, SSH, cPanel). Comfortable living in the query profiler when a page is slow, and I use Claude Code daily for AI-assisted development.

    Motivated software engineer with a strong foundation in OOP, software architecture and database systems from a BS at the University of the Punjab (CGPA 3.51) — which shows up in how I structure services, model data and reason about performance rather than just making things work. Adept at problem-solving and collaborating in agile environments with a focus on clean, efficient and testable code.
